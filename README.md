# Платформа совместных покупок (Joint Purchases)

## Назначение
Веб-платформа для организации совместных покупок. Приложение позволяет
пользователю-организатору создать совместную покупку определённого товара,
а другим пользователям — присоединиться к ней, чтобы приобрести товар оптом
по более выгодной цене. Платформа помогает объединять покупателей, отслеживать
набор нужного количества участников и фиксировать оплату.

## Целевая аудитория
- Частные покупатели, желающие покупать товары оптом по сниженной цене.
- Организаторы совместных покупок, координирующие группы участников.
- Небольшие сообщества (коллеги, соседи, тематические группы), совершающие
  регулярные совместные заказы.

## Предметная область
Совместная покупка — это форма коллективного приобретения товара, при которой
несколько участников объединяют заказы, чтобы получить оптовую цену. Организатор
создаёт покупку, указывает товар, его цену и минимальное количество участников,
необходимое для того, чтобы покупка состоялась. Участники присоединяются к покупке
и вносят платёж за свою долю. Когда набирается нужное количество участников и
платежи подтверждены, покупка считается состоявшейся.

## Основные сущности
- **Пользователь** — участник платформы (организатор или покупатель).
- **Совместная покупка** — заказ товара с указанием цены, минимального и
  максимального числа участников и текущего статуса.
- **Товар** — предмет покупки с названием и стоимостью.
- **Участие в покупке** — связь пользователя с конкретной совместной покупкой.
- **Платёж** — оплата участником своей доли в совместной покупке.

## Основные функции
- Проверка возможности присоединиться к совместной покупке (есть ли свободные места).
- Расчёт стоимости участия для одного покупателя с учётом комиссии платформы.
- Определение статуса совместной покупки (набирается / состоялась).
- Проверка статуса платежа участника.
