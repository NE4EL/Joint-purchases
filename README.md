# Платформа совместных покупок (Joint Purchases)

## Назначение
Консольное приложение для организации совместных покупок. Пользователь-
организатор создаёт совместную покупку товара, а другие пользователи
присоединяются к ней, чтобы приобрести товар оптом по более выгодной цене.
Приложение ведёт учёт покупок и участий, отслеживает набор нужного числа
участников и сохраняет данные между запусками.

## Целевая аудитория
- Частные покупатели, желающие покупать товары оптом по сниженной цене.
- Организаторы совместных покупок, координирующие группы участников.
- Небольшие сообщества (коллеги, соседи, тематические группы).

## Предметная область
Совместная покупка — форма коллективного приобретения товара, при которой
несколько участников объединяют заказы ради оптовой цены. Покупка состоится,
когда наберётся заданное минимальное число участников и не будет превышено
максимальное.

## Основные сущности
- **Пользователь** — участник платформы (организатор или покупатель).
- **Совместная покупка** — заказ товара с ценой, минимальным и максимальным
  числом участников.
- **Товар** — предмет покупки (название и стоимость).
- **Участие в покупке** — связь пользователя с конкретной покупкой.
- **Платёж** — оплата участником своей доли (статус платежа).

## Основные функции
- Просмотр и поиск совместных покупок по названию товара.
- Отбор покупок по цене и сортировка по возрастанию цены.
- Проверка возможности присоединиться (есть ли свободные места).
- Присоединение к покупке и отмена участия.
- Расчёт стоимости участия с учётом комиссии платформы.
- Определение статуса покупки и статуса платежа.

## Структура проекта
- `main.py` — точка запуска, меню приложения и вывод данных;
- `purchases.py` — функции работы с совместными покупками;
- `participations.py` — функции работы с участием в покупках;
- `storage.py` — загрузка и сохранение данных (JSON);
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы данных (`purchases.json`, `participations.json`);
- `tests/` — автоматизированные тесты pytest.

## Формат хранения данных
Данные хранятся в JSON-файлах каталога `data/`:
- `purchases.json` — список покупок (`id`, `product`, `price`,
  `min_participants`, `max_participants`);
- `participations.json` — список участий (`id`, `purchase_id`, `user`).

При запуске приложение читает файлы, при изменениях — сохраняет их заново.
Чтение и запись выполняются через контекстный менеджер `with` с обработкой
исключений (отсутствие файла, некорректный JSON).
